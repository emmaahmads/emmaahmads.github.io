Project Overview

Summafy is an enterprise-grade AI-powered document summarization platform built on a serverless-first architecture. It leverages Retrieval Augmented Generation (RAG) for enhanced context-aware summarization, with event-driven workflows orchestrating document processing pipelines from ingestion to delivery.

Architecture Highlights

  • • Serverless event-driven workflows
  • • Self-hosted RAG with vector databases
  • • Microservices on AWS with Docker
  • • OpenTelemetry observability

Infrastructure

  • • Terraform & CloudFormation IaC
  • • AWS SAM for serverless
  • • GitHub Actions CI/CD
  • • Multi-repo architecture
