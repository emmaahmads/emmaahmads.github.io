Project Overview

Summafy started as a learning project for me to learn Backend and Cloud Application Development. It evolves into a full-blown AI-powered document summarization platform with multiple components and sophisticated workflows. I integrated AWS serverless components that include an orchestration workflows for S3 event, self-hosted RAG and document processing pipelines. The platform is deployed entirely on AWS utilizing Docker, EC2, S3, RDS, ECR, Lambda and managed with Terraform, CloudFormation and AWS SAM with Github Actions for CI/CD. Ongoing work includes transforming the platform into microservices architecture to enhance scalability and maintainability.
