Architecture Highlights

Modular Design

Separates UI, orchestration, and LLM layers for clean boundaries and extensibility.

LLM-Agnostic

Provider-agnostic design allows swapping providers (OpenAI, Ollama) without code changes.

Containerized

Flask services with Docker containerization and Docker Compose for reproducible environments.
